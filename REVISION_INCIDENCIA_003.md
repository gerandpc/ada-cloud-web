# Incidencia 003 — Flujo y privacidad de Programas

- Los recursos se consultan únicamente para los programas que el usuario ya tiene autorizados.
- Los enlaces externos se limitan a protocolos HTTP/HTTPS.
- Se evita crear dos programas con igual curso, materia, año y versión para el mismo docente.
- Se corrige el mensaje posterior a una edición para diferenciar cambios de una creación nueva.
